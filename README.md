# README

The goal of this project is to automate repetitive processes and tasks. You are free to configure your own workflows, so please be careful with the actions and configurations you define.

The project is structured around four main concepts: **Processes, Tasks, Steps, and Components.**

## Processes

Processes are simply used to assign a unique name to each workflow.

## Tasks

You can configure one or multiple tasks within a process. Each task is assigned an order number that determines its execution sequence.

## Steps

This is the core part of the project. Here you define what each task will actually do.

There are several types of components available, although all of them are currently in testing mode.

- You can define variables to store the output values generated during execution.
- You can use variables in the `Value` field by pressing the `@` key.
- You can use functions by pressing the `$` or `!` key.

## Components

Components provide specific functionality that can be used within task steps.
